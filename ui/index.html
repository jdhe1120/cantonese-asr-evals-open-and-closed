Scores
Corpus CER is all errors ÷ all characters in the group, so long clips weigh more (the usual way speech-recognition papers report CER). Average clip CER averages each clip's own CER, so every clip counts the same (the community benchmark, hon9kon9ize); it runs higher when a model fails on short clips. Groups are scored separately, never pooled. A model that hasn't covered every clip shows n/N. A gap of a point or two between models is within noise: read the diffs.
Traditional scores without converting to simplified, on the clips whose references are traditional (the Guangzhou sets and the mixed set's simplified references drop out). Hong Kong and Taiwan variant spellings count the same. Rows ending in + HK converter (→繁 in Browse clips) are that model's transcripts run through a converter (OpenCC plus cantocaptions-ai's Cantonese table: 系→係, 只→隻…), as an app would show them.
